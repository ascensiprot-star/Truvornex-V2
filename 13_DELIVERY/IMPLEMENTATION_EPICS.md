# Implementation Epics

- **E01 Product evidence:** validated actor problems, workflow maps, alternatives, pilot cohort, outcome metrics.
- **E02 Platform foundation:** repo, CI, configuration, API conventions, migrations, telemetry, security baseline.
- **E03 Account/authority:** account, auth, recovery, organization, delegation, audit.
- **E04 Trust/evidence:** credential records, verification adapters, freshness, challenge/appeal.
- **E05 Catalog/capacity:** provider capability, listings, availability, allocation correctness.
- **E06 Discovery/matching:** search, eligibility, relevance, fairness, cold-start.
- **E07 Economic lifecycle:** request, offer, agreement, order, fulfillment, change, cancellation.
- **E08 Financial boundary:** PSP selection/contracts, orchestration, signed callbacks, reconciliation, refunds.
- **E09 Documents:** canonical invoice model, structured formats, jurisdiction adapters.
- **E10 Communication/disputes:** messaging, notification, complaint, evidence preservation.
- **E11 Native mobile:** Flutter architecture, accessibility, roles, offline-safe flows, platform release.
- **E12 Simon:** inventory, governance, retrieval, safe tools, evaluation/rollback.
- **E13 Country enablement:** capability profiles, legal review, localization, local integrations.
- **E14 Operations/governance:** support, SRE, incident response, fairness monitoring, published policies.

Epic completion requires end-to-end acceptance and operational ownership, not just screens or endpoints.
