# Dependency Graph and Build Order

This is a dependency order, not a calendar or time estimate.

**Foundation:** problem evidence/scope → actors → glossary → requirements/acceptance → regulatory applicability → threat model → ADRs.

**Core platform:** authentication/account → organization/authority → country capability registry → audit/policy → catalog/capability → resources/availability → request/discovery/matching → offers/agreements → orders/fulfillment.

**Economic completion:** PSP partner/legal perimeter → payment orchestration → signed webhook processing → financial records/reconciliation → invoices/documents → disputes/refunds/appeals.

**Intelligence/expansion:** data governance/event quality → analytics → Simon use-case evaluation → approved AI flows → additional country/standards adapters.

**Mobile:** design/accessibility/localization → auth/context switching → discovery/catalog → request/offer/agreement → order/fulfillment → payment/documents → disputes/profile/Simon.

**Operations/release:** CI/security → observability → backup/restore → runbooks → sandbox integration → country launch gate → production rollout/monitoring.

Parallelize only when contracts are stable and boundaries explicit.
