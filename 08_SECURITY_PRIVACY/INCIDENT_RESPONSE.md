# Security and Privacy Incident Response

Incident types: account compromise; data exposure; payment fraud/reconciliation mismatch; provider compromise; availability incident; ransomware; insider misuse; AI/data leakage; mobile release compromise; privacy-rights failure.

Lifecycle: detect → triage → contain → preserve evidence → assess impact → notify required parties/authorities where applicable → eradicate → recover → validate → post-incident review.

Maintain incident roles, contacts, severity definitions, escalation, forensic evidence process, communications templates, legal/privacy review, recovery runbooks, and tabletop exercises. Do not assert breach-notification deadlines without checking law and role. Record discovery/awareness time, data affected, countries, processors, and notification decision.
